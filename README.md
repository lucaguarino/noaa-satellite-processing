## <a name="english"></a> 🇬🇧 English

### 🎯 Project Overview
End-to-end reception and digital signal processing of NOAA weather satellite images (e.g., NOAA-15). This project covers the full engineering cycle: from capturing radio frequency waves using custom-built RF hardware to applying digital signal processing in Python to extract APT (Automatic Picture Transmission) images from the AVHRR instrument.

### 🛠️️ Technical Implementation
* **Digital Signal Processing (Python):** AM demodulation, algorithmic resampling to adjust frequencies, and temporal synchronization of asynchronous signals using Jupyter Notebooks.
* **Hardware & RF Reception:** Design, assembly, and testing of a custom **Dipole-V antenna** optimized for NOAA frequencies, including a 3D-printed mount and SMA to coaxial connections.

## <a name="español"></a> 🇪🇸 Español

### 🎯 Resumen del Proyecto
Recepción y procesamiento digital de señales de la red de satélites meteorológicos NOAA (ej. NOAA-15). Este proyecto abarca el ciclo completo de ingeniería: desde la captura de ondas de radiofrecuencia mediante hardware propio, hasta el procesamiento matemático en Python para extraer imágenes APT del instrumento AVHRR.

### 🛠️️ Implementación Técnica
* **Procesamiento Digital (Python):** Demodulación AM, *resampling* algorítmico para ajuste de frecuencias y sincronización temporal de señales utilizando Jupyter Notebooks.
* **Infraestructura (Hardware):** Diseño, construcción y testeo de una **antena Dipolo-V**, integrando un soporte impreso en 3D y conexiones SMA a cable coaxial sin pérdida de continuidad.
